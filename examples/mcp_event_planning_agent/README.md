# Event Planning Agent

AI-powered event planning and coordination for personal and professional events with comprehensive logistics management.

## Features

### 🎉 **Comprehensive Event Planning**
- Event concept and theme development
- Venue selection and booking coordination
- Guest list management and invitations
- Timeline and logistics coordination

### 🔧 **Logistics Coordination**
- Vendor selection and management
- Setup and breakdown coordination
- Equipment and supply procurement
- Technology and AV system setup

### ✨ **Guest Experience Optimization**
- Personalized welcome processes
- Networking facilitation
- Interactive engagement activities
- Real-time feedback and adaptation

## Installation & Usage

```bash
cd examples/mcp_event_planning_agent
cp mcp_agent.secrets.yaml.example mcp_agent.secrets.yaml
uv run main.py
```

Perfect for event organizers wanting comprehensive planning assistance and memorable experiences!
