# Travel Planning Agent

AI-powered travel planning agent that creates comprehensive itineraries, optimizes bookings, and manages trip logistics for seamless travel experiences.

## Features

### ✈️ **Itinerary Creation**
- Day-by-day activity planning
- Attraction and restaurant recommendations
- Transportation logistics
- Cultural insights and local tips

### 💰 **Booking Optimization**
- Flight and hotel price comparison
- Package deal analysis
- Loyalty program optimization
- Flexible booking strategies

### 📋 **Trip Management**
- Document and visa requirements
- Packing lists and preparations
- Real-time updates and alerts
- Emergency planning and contacts

## Installation & Usage

```bash
cd examples/mcp_travel_planning_agent
cp mcp_agent.secrets.yaml.example mcp_agent.secrets.yaml
uv run main.py
```

Perfect for travelers wanting comprehensive trip planning and optimization assistance!
