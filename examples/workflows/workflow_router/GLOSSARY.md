# 🧒 어린이를 위한 기술 용어 설명서
# Technical Terms Glossary For Children

컴퓨터와 프로그래밍에서 사용하는 어려운 단어들을 쉽게 설명해요!

## 🤖 에이전트 (Agent)
**쉬운 설명:** 로봇 도우미 같은 것이에요. 사람 대신 일을 해주는 컴퓨터 프로그램이에요.
**예시:** 청소 로봇이 집을 청소해주는 것처럼, 컴퓨터 에이전트는 정보를 찾아주거나 메시지를 보내주어요.

## 🧭 라우터 (Router)
**쉬운 설명:** 교통 경찰관 같은 것이에요. 어디로 가야 할지 알려주는 안내원이에요.
**예시:** 우체부가 편지를 올바른 집에 배달하는 것처럼, 라우터는 요청을 올바른 에이전트에게 보내주어요.

## 🔑 API 키 (API Key)
**쉬운 설명:** 특별한 비밀번호에요. 컴퓨터 서비스를 사용할 수 있게 해주는 열쇠같은 것이에요.
**예시:** 집 열쇠로 집에 들어가는 것처럼, API 키로 컴퓨터 서비스에 들어갈 수 있어요.

## 🎯 키워드 (Keyword)
**쉬운 설명:** 중요한 단어에요. 컴퓨터가 무엇을 찾아야 하는지 알려주는 힌트 단어에요.
**예시:** "강아지"라고 말하면 강아지 사진을 찾아주는 것처럼, 키워드를 보고 무엇을 해야 할지 알아요.

## 🧠 LLM (Large Language Model)
**쉬운 설명:** 매우 똑똑한 컴퓨터 두뇌에요. 사람처럼 말하고 생각할 수 있어요.
**예시:** 매우 똑똑한 친구가 질문에 답해주는 것처럼, LLM도 질문을 받으면 답을 해줘요.

## 💾 데이터베이스 (Database)
**쉬운 설명:** 컴퓨터의 큰 서랍장이에요. 많은 정보를 정리해서 보관하는 곳이에요.
**예시:** 도서관에서 책을 찾기 쉽게 정리해두는 것처럼, 데이터베이스는 정보를 찾기 쉽게 정리해둬요.

## 🕷️ 웹 스크래핑 (Web Scraping)
**쉬운 설명:** 인터넷에서 정보를 모으는 것이에요. 마치 꽃에서 꿀을 모으는 벌처럼요.
**예시:** 여러 쇼핑몰을 돌아다니며 가격을 비교하는 것처럼, 웹 스크래핑은 여러 웹사이트에서 정보를 모아와요.

## 🖥️ CLI (Command Line Interface)
**쉬운 설명:** 글자로만 컴퓨터와 대화하는 방법이에요. 마우스나 버튼 대신 글자를 써요.
**예시:** 터치스크린 대신 리모콘 버튼을 누르는 것처럼, CLI는 글자로 명령을 내려요.

## 📦 가상환경 (Virtual Environment)
**쉬운 설명:** 컴퓨터 안의 작은 방이에요. 다른 프로그램들과 섞이지 않게 따로 보관하는 공간이에요.
**예시:** 장난감을 다른 상자에 따로따로 정리하는 것처럼, 가상환경은 프로그램을 따로따로 보관해요.

## 🔌 플러그인 (Plugin)
**쉬운 설명:** 레고 블록 같은 것이에요. 기본 프로그램에 새로운 기능을 추가할 수 있어요.
**예시:** 휴대폰에 새로운 앱을 설치하는 것처럼, 플러그인은 프로그램에 새로운 능력을 추가해줘요.

## 🔄 MCP (Model Context Protocol)
**쉬운 설명:** 컴퓨터들이 서로 대화할 때 사용하는 공통 언어에요. 모든 컴퓨터가 이해할 수 있는 방법이에요.
**예시:** 전 세계 사람들이 영어로 대화하는 것처럼, MCP는 컴퓨터들이 서로 이해할 수 있는 방법이에요.

## 🧪 테스트 (Test)
**쉬운 설명:** 프로그램이 제대로 작동하는지 확인하는 것이에요. 숙제를 다시 검사하는 것과 같아요.
**예시:** 자전거를 타기 전에 브레이크가 잘 작동하는지 확인하는 것처럼, 테스트는 프로그램이 잘 작동하는지 확인해요.

## 📚 문서화 (Documentation)
**쉬운 설명:** 프로그램 사용법을 적어둔 설명서에요. 요리책처럼 어떻게 사용하는지 알려줘요.
**예시:** 새로운 장난감의 설명서를 읽는 것처럼, 문서화는 프로그램을 어떻게 사용하는지 알려줘요.

## 🔒 설정 (Configuration)
**쉬운 설명:** 프로그램을 내 마음대로 조정하는 것이에요. 내가 원하는 대로 바꿀 수 있어요.
**예시:** 알람시계의 시간을 내가 원하는 시간으로 맞추는 것처럼, 설정은 프로그램을 내 마음대로 조정하는 것이에요.

## 🚨 오류 처리 (Error Handling)
**쉬운 설명:** 프로그램이 문제가 생겼을 때 어떻게 해야 할지 미리 준비해두는 것이에요.
**예시:** 비가 올 때를 대비해서 우산을 준비하는 것처럼, 오류 처리는 문제가 생겼을 때를 대비해요.
